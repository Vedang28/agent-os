Full Bug Lifecycle

Detection → triage → fix → test → document → learn

Bug Detected
Observability or Testing department spots the issue
Bug Triage Department
Classifier: reads error, checks brain for similar past bugs
Reproducer: attempts reproduction, captures exact steps
Validator: confirms repro is accurate, confirms root cause
Owning Department (e.g. Backend)
Architect: reads brain + bug report, plans the fix
Builder: implements fix using tools
Reviewer: reviews fix, max 3 revisions then escalate
Testing Department
Runs full test suite against the fix
Documentation Department
Updates any affected docs
Guardian
Gates the PR — is it safe to merge?
PR Ready for Review
Delivered to your dashboard with: fix + tests + docs + security review
Reflector
"This bug type was caused by X — next time check Y first" → playbook updated
